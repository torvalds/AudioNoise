### Scikit-Learn - 3 Schritte!

| Schritt | Befehl | Was? |
| --- | --- | --- |
| 1. Modell! | LinearRegression() | Leere AI! |
| 2. Trainieren! | model.fit(X, y) | Zeigen! Lernen! |
| 3. Vorhersagen! | model.predict([[6]]) | Neue Zahl raten! |

### AI-Regel!

1. **X = Eingabe!** z.B. Training-Stunden!

2. **y = Antwort!** z.B. Ergebnis!

3. **fit = Lernen!** predict = Raten!


```python
# ai_sklearn.py - OMQ Python AI Scikit-Learn
from sklearn.linear_model import LinearRegression
print('Scikit-Learn: Erster echter AI!')
# X = Stunden gelernt, y = Punkte in Prüfung
X = [[1],[2],[3],[4],[5]]
y = [10,20,30,40,50]
model = LinearRegression()
model.fit(X, y)
print('AI trainiert! Hat gelernt: 1 Stunde = 10 Punkte!')
vor = model.predict([[6]])
print(f'Vorhersage: 6 Stunden lernen = {vor[0]:.0f} Punkte!')
print('Echte AI! 3 Zeilen!')
```
