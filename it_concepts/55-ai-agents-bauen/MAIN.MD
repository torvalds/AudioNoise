### Agent = Loop! Nicht 1x fragen, sondern immer wieder!

```
THINK -> ACT -> OBSERVE -> REPEAT
Denken -> Machen -> Sehen -> Wiederholen
```

Beispiel: Baue EAL191! Think: Was fehlt? Act: Datei schreiben! Observe: Fehler? Repeat: Fixen!


### Dein erster Agent - 20 Zeilen Python!

```python
# agent.py - OMQ Mini-Agent
task = input('Was soll ich tun? ')
for i in range(3):
    print(f'Runde {i+1}: Denke nach...')
    print(f'Aktion: {task} - Schritt {i+1}')
    print('Beobachtung: OK, weiter!')
print('FERTIG!')
```

Starten: `python3 agent.py` - Das ist schon ein Agent! Loop + Aktion + Beobachtung!


| Teil | Was? | OMQ-Beispiel |
| --- | --- | --- |
| 1. Ziel | Was soll er? | Baue EAL191! |
| 2. Tools | Was darf er? | Datei schreiben, Bash, Suche! |
| 3. Loop | Wie oft? | Bis fertig oder max 3x! |
| 4. Stopp | Wann aufhören? | Wenn DONE! oder Fehler! |

### 3 Fehler vermeiden

1. **Endlos-Loop:** Immer Max-Runden setzen! Sonst läuft er ewig!

2. **Kein Stopp:** Ohne DONE = Nie fertig! Immer Erfolg prüfen!

3. **Zu viel auf einmal:** 1 Ziel, 1 Tool, 1 Schritt! Klein starten!
